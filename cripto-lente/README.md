# Cripto Lente

Herramienta informativa de investigación y señales para criptoactivos.

## Qué hace
- Fundamentales con dos scores: Estructura y Contexto.
- Señales con reglas estrictas (régimen BTC + pullback + RSI + volumen).
- Paper trading con comisiones, slippage, SL y TP.
- Backtester con datos históricos de Binance.
- Journal de señales con win rate real.

## Qué NO hace
- No ejecuta órdenes reales.
- No se conecta a exchanges con tu dinero.
- No predice precios.
- No es asesoramiento financiero.
